ROTATION ÉQUIPE — INSTALLATION SUR IPHONE

1. Publie ce dossier sur un hébergeur HTTPS, par exemple GitHub Pages, Netlify ou Vercel.
2. Ouvre l’adresse du site dans Safari sur l’iPhone.
3. Appuie sur Partager.
4. Choisis « Sur l’écran d’accueil ».
5. Appuie sur Ajouter.

IMPORTANT
Une PWA ne peut pas être installée correctement depuis un simple fichier local.
Elle doit être ouverte depuis une adresse web sécurisée en HTTPS.

GITHUB PAGES
- Crée un dépôt GitHub.
- Ajoute tous les fichiers de ce dossier à la racine.
- Ouvre Settings > Pages.
- Choisis Deploy from a branch, puis main / root.
- GitHub fournit ensuite une adresse HTTPS.
